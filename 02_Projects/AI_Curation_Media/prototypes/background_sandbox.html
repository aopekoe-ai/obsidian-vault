白さ100%・細かい格子状パターンの比較検証

すべて純白（#FFFFFF）の微細なベクター線で描かれた格子状のテクスチャです。
背面のグラデーション（TikTokのシアン×フューシャ等）の上に乗ることで、背景全体が「ハイテクなデジタルのキャンバス」へと変化します。

1. サイバー方眼（微細クロス付き）

24px GRID

24pxの細かい正方形の白格子。格子の交差点に小さな「＋（クロス）」が刻まれており、設計図や測量グリッドのような精密でクールなサイバー感を演出します。

2. アイソメトリック三角メッシュ

TRIANGLE 3D

斜めの破線が交差する三角形のメッシュ。ポリゴンや3D空間のような奥行き感が生まれ、フラットな背景が一気に立体的に引き締まります。

3. ドットマトリクス（精密点格子）

DOT MATRIX

線ではなく、白く輝く微細なドットが整然と等間隔に並ぶマトリクス。グラデーションの滑らかさを最も邪魔せず、洗練されたデジタル感を両立できます。

4. ハニカム六角セル

HEXAGON CELL

近未来SFのエネルギーシールドのような六角形の格子。乃愛のサイバーハッカー感や怜衣の精密なロジックを象徴する、最も個性の強い格子です。

5. コードブラケット格子

CODE BRACKETS

36px方眼の中に、微小なブラケット「 [ ] 」やドットがコードのようにさりげなく配置された遊び心ある格子。開発者メディアやAIキュレーションにぴったりです。

スクロールテスト

どの格子パターンも全画面固定（`fixed`）のため、スクロールしてもモアレ（チラつき）やカクつきが発生せず、60fpsで超高速に描画されます。
