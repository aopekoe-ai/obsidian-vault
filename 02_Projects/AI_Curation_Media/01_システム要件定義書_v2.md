## 概要
- **ドメイン:** スタードメイン
- **DNS/CDN/WAF:** Cloudflare
- **サーバー:** Contabo VPS (Ubuntu 24.04 LTS / Docker Compose / Nginx + Redis + MariaDB)
- **CMS:** WordPress (REST API & WP-CLI連携)
- **通知・運用:** Discord Webhook / Bot
- **URL構造:** 4マトリックス (`/ja/japan/`, `/ja/world/`, `/en/japan/`, `/en/world/`)
- **看板キャラクター:** 4人娘白熱討論（奏・菜々・舞・凛音）
