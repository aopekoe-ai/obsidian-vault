# AI漫画制作プロジェクト（AI Manga Project）

## 概要
キュレーションメディア『SNSにゅーす（https://sns-news.jp/）』に連動する、完全自律型Web漫画制作システムの独立プロジェクトリポジトリです。

## ドキュメント一覧
- [01_AI漫画制作システム_基本設計・総合仕様書.md](./01_AI漫画制作システム_基本設計・総合仕様書.md)
  - コアコンセプト・5大欠陥と対策・10大アンチパターン
  - 4人娘キャラクター設定（専門スキル × ギャップ属性）
  - 黄金の4コマ（縦スクロール4パネル）構成
  - 3層完全分離アーキテクチャ（脚本JSON × 文字なし画像生成 × HTML/SVG組版）
  - 構造化データ仕様（JSON Schema）
  - 完全オリジナル性担保・知的財産権（IP）絶対遵守憲章（外部作品名・意匠類似の完全排除）
  - 開発ロードマップ（Phase 1〜4）
